## 1. 产品概述

### 1.1 产品定位

SoloPilot 是一个面向"有意向或正在运营一人公司"的用户的 AI 驱动规划助手平台。通过结构化的信息采集、MBTI 性格测评和智能推荐算法，为用户生成个性化的创业方向建议、AI 员工配置方案和城市选择策略，帮助用户以最低试错成本启动一人公司。

### 1.2 产品愿景

让每一个有想法的个体，都能获得专业级的一人公司创业规划指导，消除从"想"到"做"之间的认知鸿沟和信息差。

### 1.3 核心价值主张

| 价值维度 | 具体内容 |
|----------|----------|
| 个性化 | 基于用户身份、能力、动机、资源、性格五维度生成定制方案 |
| 低门槛 | 无需创业经验，对话式引导逐步收集信息，用大白话而非专业术语 |
| 实操性 | 不仅给方向，还给具体的 AI 员工搭建方案、工具选型、行动清单 |
| 可信度 | 所有建议基于一人公司方法论、行业案例和政策研究 |

### 1.4 目标用户

| 用户类型 | 特征 | 核心诉求 |
|----------|------|----------|
| 在职员工（副业意向） | 有稳定工作，想利用业余时间尝试创业 | "我能做什么？风险有多大？从哪开始？" |
| 自由职业者 | 已在独立工作，但缺乏系统化运营思路 | "怎么把零散的收入变成可持续的生意？" |
| 在校学生 | 时间充裕但经验有限，试错成本低 | "一人公司是什么？适合我吗？怎么开始？" |
| 待业/刚离职者 | 紧迫感强，需要尽快产生收入 | "我现在该做什么？最快多久能有收入？" |

## 2. 业务流程

### 2.1 用户完整旅程

```
注册/登录 --> 阅读一人公司介绍 --> 搜集个人信息 --> MBTI测评 -->
生成用户画像(后台) --> 提供初步建议 --> 提供总结性建议 -->
搜集用户意见 --> 合规性审查 --> AI员工配置建议 --> 长期复盘指导
```

### 2.2 各步骤说明

| 步骤 | 编号 | 名称 | 说明 |
|------|------|------|------|
| 1 | S01 | 注册/登录 | 支持微信授权登录、手机号登录 |
| 2 | S02 | 阅读一人公司介绍 | 以通俗化方式展示一人公司的定义、优劣势、核心矛盾，建立认知基础 |
| 3 | S03 | 搜集个人信息 | 分步采集用户的城市、性别、技能、行业偏好等结构化数据 |
| 4 | S04 | MBTI 测评 | 93 题完整版 MBTI 测试，结果用于后续推荐算法 |
| 5 | S05 | 生成用户画像 | 后台综合 S03、S04 数据，生成用户画像标签 |
| 6 | S06 | 提供初步建议 | 基于用户画像，推荐七大行业方向中适合的方向，以及用户所属四型分类 |
| 7 | S07 | 提供总结性建议 | 汇总所有分析结果，给出综合创业方案建议 |
| 8 | S08 | 搜集用户意见 | 收集用户对建议的反馈，用于优化后续推荐 |
| 9 | S09 | 合规性审查 | 提供一人公司相关的法律、税务、注册合规指引 |
| 10 | S10 | AI 员工配置建议 | 根据用户业务类型，推荐个性化的 AI 智能体组合方案 |
| 11 | S11 | 长期复盘指导 | 提供持续运营阶段的复盘框架和迭代指导 |

## 3. 功能需求

### 3.1 模块一：用户注册与登录

| 需求项 | 优先级 | 说明 |

### 3.2 模块二：一人公司介绍

| 需求项 | 优先级 | 说明 |
|--------|--------|------|
| 一人公司定义展示 | P0 | 基于已有文案的通俗化介绍 |
| 优劣势对比展示 | P0 | 结构化呈现一人公司的优势与挑战 |
| 核心矛盾与解决思路 | P0 | 时间精力有限 vs 事情多，展示两种解决方向 |
| 行业案例展示 | P1 | 展示国内外成功案例，增强可信度和参考价值 |

**内容来源**：`文字资料/一人公司简介.md`、`文字资料/一人公司.md`

### 3.3 模块三：个人信息采集

采集采用**对话式引导**模式，每次只问一个问题，根据回答动态调整后续问题。

| 采集项 | 类型 | 选项/说明 |
|--------|------|-----------|
| 所在城市 | 单选 | 一线城市 / 新一线城市 / 二线城市 / 三线及以下 |
| 性别 | 单选（可选） | 男 / 女 |
| 工作强度喜好 | 单选 | 007 / 996 / 965 / 越少工作越好 |
| 核心技能 | 单选 | 写作内容 / 编程技术 / 设计美术 / 销售商务 / 教学培训 / 行业专业 / 暂不确定 / 其他 |
| 七大方向偏好 | 单选 | 知识付费与内容创作 / 独立开发与微型SaaS / 专业技能咨询与服务 / 跨境与利基电商 / AI驱动的服务业务 / 实体轻服务 / 信息中介与资源对接 |
| 成立一人公司目的 | 填写 | 开放式文本输入 |
| 工作时间偏好 | 单选 | 固定时间坐班型（长白班/夜猫子）/ 零碎工作时间类型 |

**设计原则**（来自问询文案设计指南）：
- 从"你在做什么"切入，不从"你想做什么"开头
- 先收集事实，再询问动机
- 每个问题只收集一个信息点
- 给选项，不让用户从零开始想

**内容来源**：`文字资料/个人信息搜集内容.md`、`文字资料/一人公司用户问询文案设计.md`

### 3.4 模块四：MBTI 测评

| 需求项 | 优先级 | 说明 |
|--------|--------|------|
| 93 题完整问卷 | P0 | 分两部分：情境行为题（1-26题）+ 词语偏好题（27-93题） |
| 自动计分 | P0 | 按四个维度（E/I、S/N、T/F、J/P）自动统计得分 |
| 结果展示 | P0 | 输出四字母 MBTI 类型 |
| 性格解析 | P0 | 展示该类型对一人公司的具体影响分析 |

**计分规则**：
- E vs I（外向 vs 内向）：21 道题
- S vs N（实感 vs 直觉）：通过词义判断归属
- T vs F（思考 vs 情感）：通过词义判断归属
- J vs P（判断 vs 知觉）：通过词义判断归属

**内容来源**：`文字资料/MBTI 测试问卷(1).md`、`文字资料/mbit测评结果解析.md`

### 3.5 模块五：用户画像生成

后台综合以下数据生成用户画像：

| 数据来源 | 画像维度 |
|----------|----------|
| 城市等级 | 成本承受能力、政策可获性、客户资源环境 |
| 工作强度偏好 | 适合的业务节奏和工作模式 |
| 核心技能 | 最匹配的行业方向 |
| 七大方向偏好 | 用户自身兴趣倾向 |
| MBTI 类型 | 创业风格、盲区、需要补位的方向 |
| 成立目的 | 推荐策略侧重点（稳 vs 快） |

画像输出标签示例：
- "一线城市 / 技术背景 / INTJ / 偏好独立开发 / 目标月入3万+"
- "三线城市 / 内容创作 / ENFP / 偏好知识付费 / 从副业起步"

### 3.6 模块六：初步建议 -- 七大方向 + 四型分类

#### 6.1 七大行业方向推荐

基于用户画像，从以下七大方向中推荐 2-3 个最适合的方向，按匹配度排序：

| 编号 | 方向 | 核心特征 | 适合的用户特征 |
|------|------|----------|----------------|
| 1 | 知识付费与内容创作 | 门槛最低，边际成本趋零 | 写作能力强、有行业知识积累 |
| 2 | 独立开发与微型 SaaS | 一次开发无限售卖 | 编程能力、产品思维 |
| 3 | 专业技能咨询与服务 | 高客单价，专业壁垒高 | 法律/财务/医疗等专业背景 |
| 4 | 跨境与利基电商 | 选品能力+流量运营 | 有电商经验、选品能力 |
| 5 | AI 驱动的服务业务 | 2025-2026 年增长最快 | AI 工具使用经验、技术服务能力 |
| 6 | 实体轻服务 | 低投入、本地化 | 有本地资源、社区运营能力 |
| 7 | 信息中介与资源对接 | 投入低但依赖人脉 | 人脉资源丰富、信息整合能力 |

每个推荐方向需展示：
- 匹配理由（结合用户画像解释为什么适合）
- 参考案例（国内外成功案例）
- 预期收入范围
- 启动建议

**内容来源**：`文字资料/一人公司行业与案例.md`

#### 6.2 四型用户分类

根据用户画像，将其归类为以下四型之一，并给出对应的创业策略：

| 类型 | 用户画像 | 核心建议 |
|------|----------|----------|
| 保守型 | 在职、时间少、低预算、怕失败 | 从副业开始，推荐低风险路径 |
| 平衡型 | 在职/自由职业、有一定时间、中等预算 | 提供 2-3 个可选方案让用户选择 |
| 激进型 | 待业/全职投入、高预算、不怕失败 | 直接推荐最优路径，鼓励快速行动 |

**内容来源**：`文字资料/一人公司用户问询文案设计.md`（用户类型判断矩阵）

### 3.7 模块七：总结性建议

汇总模块六的分析，生成一份综合创业方案报告，包含：

| 板块 | 内容 |
|------|------|
| 你的画像 | 一段话概括用户的核心特征和优势 |
| 推荐方向 | Top 2-3 个推荐方向及匹配理由 |
| 策略建议 | 营销优先 vs 开发优先的推荐 |
| 城市建议 | 基于当前城市和业务类型的城市选择建议 |
| 首月行动清单 | 具体的 30 天行动计划（可执行步骤） |
| 预期时间线 | 何时能产生第一笔收入的中性预期 |

### 3.10 模块十：AI 员工配置建议

#### 10.1 AI 员工选择测评

通过 10 道选择题评估用户的业务特征，匹配到以下 6 种方案之一：

| 方案 | 适用对象 | 核心 AI 员工组合 |
|------|----------|------------------|
| A：内容创作者型 | 靠内容吸引客户 | 内容创作助手 + 社媒运营员 + SEO优化师 + 配图生成器 |
| B：产品/服务运营型 | 有明确产品在卖 | 智能客服 + 销售助理 + 运营管家 + 竞品监控员 |
| C：技术创业者型 | 技术背景，做独立开发 | 技术客服 + 文档生成器 + 用户反馈分析员 + 内容营销员 |
| D：咨询/教练型 | 专业咨询服务 | 内容营销员 + 邮件/私域运营员 + 日程管家 + 方案生成器 |
| E：电商卖家型 | 电商（含跨境） | 智能客服(电商版) + 竞品价格监控 + 产品文案员 + 财务记账员 |
| F：起步探索型 | 筹备期，零基础 | 万能助理 + 内容创作助手 |

#### 10.2 AI 员工详情展示

为用户展示每个推荐角色的：
- 角色职责描述
- 能做什么 / 做不了什么
- 需要用户提供什么
- 推荐工具与平台
- 预估月费成本

#### 10.3 搭建五步法指导

| 步骤 | 内容 |
|------|------|
| 1 | 梳理业务流程，标注每个任务的频率和重复程度 |
| 2 | 选择最痛的单点，搭建第一个 AI 员工 |
| 3 | 封装工作流，从"实习生"升级为"正式员工" |
| 4 | 串联多个 Agent，形成自动化流水线 |
| 5 | 持续迭代优化，每周 review 输出质量 |

**内容来源**：`文字资料/一人公司AI员工搭建指南.md`、`文字资料/一人公司AI员工选择指南.md`

## 7. 关键设计约束

### 7.1 内容原则

- 全文使用大白话，禁止出现"MVP""PMF""LTV""MRR"等未经解释的专业术语
- 首次出现术语时需用通俗语言解释（如："MVP 就是你的产品的最小可用版本"）
- 所有建议需附带数据支撑或案例参考，不做空洞鼓励
- 严格禁止 emoji，文档和界面均不使用

### 7.2 交互原则

- 对话式引导每次只问一个问题，不一次展示多个表单字段
- 每个问题提供 3-5 个预设选项，保留"其他"空间
- 提交后立即展示个性化结果，不让用户"白填"
- 全流程需有进度指示（对话式用"还有最后一个问题"，表单式用进度条）

### 7.3 信息采集原则（来自问询文案设计指南）

| 原则 | 说明 |
|------|------|
| 从现状切入 | 问"你现在在做什么"，不问"你想做什么" |
| 先事实后动机 | 身份 --> 能力 --> 现状 --> 动机 --> 计划 |
| 单一信息点 | 每个问题只收集一个维度的信息 |
| 提供选项 | 不让用户从零开始思考 |

## 9. 项目风险与缓解

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| 用户中途流失 | 信息采集步骤多（11步），可能导致用户放弃 | 将核心流程压缩至 5-7 步，非核心步骤（S09/S11）移至后续按需访问 |
| MBTI 测评过长 | 93 题可能导致答题疲劳 | 允许中断保存，支持分多次完成；提供"快速版"（约 30 题）作为备选 |
| 建议泛化 | 推荐结果不够个性化，用户觉得"谁都能用" | 推荐结果必须包含"为什么适合你"的个性化解释，引用用户的具体回答 |
| 黑客松时间限制 | 48 小时内完成开发，功能可能做不全 | 按 P0/P1/P2 分优先级，P0 功能必须完成，P1 视情况裁剪，P2 不做 |
